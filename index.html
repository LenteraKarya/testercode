Informasi Aplikasi

BARJAS - Bantuan Barang dan Jasa

Aplikasi BARJAS adalah sistem informasi untuk mengelola data bantuan barang dan jasa yang diberikan oleh Dinas Peternakan dan Perikanan Situbondo kepada kelompok masyarakat.

Fitur Utama:
  • Input data penerima bantuan dengan informasi lengkap
  • Penyimpanan data secara lokal di browser
  • Pencarian dan filter data
  • Ekspor data ke Excel dan PDF
  • Statistik dan visualisasi data
  • Backup dan restore data
  • Manajemen link Google Drive
  • Fitur undo untuk mengembalikan data
Teknologi:
HTML5 CSS3 JavaScript Bootstrap 5 Chart.js jspdf SheetJS

Panduan Penggunaan

  1. Buka tab Input & Data
  2. Isi semua field yang wajib diisi (ditandai dengan asterisk)
  3. Klik tombol Ambil Lokasi untuk mendapatkan koordinat GPS
  4. Tambahkan link Google Drive jika diperlukan
  5. Klik tombol Simpan Data untuk menyimpan

  1. Buka tab Input & Data
  2. Gunakan filter untuk menyaring data yang ingin dicetak
  3. Klik tombol Cetak untuk mencetak data
  4. Atau klik tombol Excel atau PDF untuk ekspor data

  1. Buka tab Backup & Restore
  2. Di bagian Backup Data, tentukan nama file backup
  3. Klik tombol Backup Data ke File
  4. File JSON akan diunduh ke perangkat Anda
  5. Simpan file backup di lokasi yang aman
