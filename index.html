Tentang Aplikasi

Informasi Aplikasi
APLIKASI BARJAS (Bantuan dan Jasa)

Aplikasi ini dikembangkan untuk Dinas Peternakan dan Perikanan Kabupaten Situbondo untuk mengelola data serah terima bantuan kepada KUB (Kelompok Usaha Bersama).

Fitur Utama:
  • Input data serah terima bantuan
  • Penyimpanan link Google Drive untuk foto, video, dan dokumen
  • Pencarian dan filter data
  • Ekspor data ke PDF dan Excel
  • Backup dan restore data
  • Statistik dan visualisasi data
Pengembangan
Teknologi yang Digunakan:
  • HTML5, CSS3, JavaScript (ES6+)
  • Bootstrap 5.3.0
  • Font Awesome 6.4.0
  • Chart.js untuk visualisasi data
  • jsPDF dan jsPDF-AutoTable untuk ekspor PDF
  • SheetJS (xlsx) untuk ekspor Excel
