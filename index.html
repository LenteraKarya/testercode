Tentang Aplikasi

Informasi Aplikasi
APLIKASI BARJAS (Bantuan Barang dan Jasa)

Aplikasi ini dikembangkan untuk Dinas Peternakan dan Perikanan Kabupaten Situbondo untuk memudahkan pengelolaan data bantuan barang dan jasa.

Fitur Utama:
  • Input data penerima bantuan dengan validasi
  • Penyimpanan data di browser (localStorage)
  • Ekspor data ke Excel dan PDF
  • Backup dan restore data
  • Statistik dan grafik data
  • Manajemen link Google Drive
  • Format otomatis nomor WhatsApp
  • Deteksi lokasi otomatis
  • Cetak data per individu
Teknologi:
  • HTML5, CSS3, JavaScript (ES6+)
  • Bootstrap 5.3.0
  • Font Awesome 6.4.0
  • Chart.js untuk grafik
  • jsPDF untuk ekspor PDF
  • SheetJS untuk ekspor Excel
