Backup & Restore Data

Backup Data

Backup data Anda untuk mencegah kehilangan data. Data akan diunduh dalam format Excel.

Restore Data

Restore data dari file backup. Pastikan file yang diunggah adalah file backup yang valid.

Informasi Penyimpanan Data
Penyimpanan Lokal

Data disimpan secara lokal di browser Anda menggunakan teknologi localStorage. Data akan tetap tersimpan meskipun browser ditutup.

Penting

Lakukan backup data secara berkala. Data dapat hilang jika cache browser dibersihkan atau menggunakan browser/device berbeda.

Bantuan & Panduan
Panduan Penggunaan

Isi form input data dengan lengkap dan benar. Pastikan NIK sesuai dengan KTP dan nomor WhatsApp aktif.

Pergi ke menu Backup & Restore, lalu klik tombol "Backup ke Excel" atau "Backup ke JSON".

Pilih file backup yang sebelumnya telah diunduh, lalu klik tombol "Restore Data".
Kebijakan Privasi

Data yang disimpan dalam aplikasi ini hanya disimpan secara lokal di perangkat Anda. Kami tidak mengumpulkan, menyimpan, atau membagikan data Anda ke pihak manapun.

Pastikan untuk melakukan backup data secara berkala untuk mencegah kehilangan data.

Jika Anda memiliki pertanyaan, silakan hubungi Dinas Peternakan dan Perikanan Situbondo.
