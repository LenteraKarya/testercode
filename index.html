Tentang Aplikasi

Informasi Aplikasi
APLIKASI BARJAS (Bantuan Peternakan dan Perikanan)

Aplikasi ini dikembangkan untuk Dinas Peternakan dan Perikanan Kabupaten Situbondo guna memudahkan pendataan dan pelacakan distribusi bantuan kepada masyarakat.

Fitur Utama:
  • Input data penerima bantuan
  • Manajemen data bantuan
  • Statistik dan grafik distribusi bantuan
  • Backup dan restore data
  • Integrasi dengan Google Drive
  • Ekspor data ke Excel dan PDF
Versi: 1.0.0
Terakhir Diupdate: 15 Juli 2025

Panduan Penggunaan

  1. Buka tab Input & Data
  2. Isi semua field yang wajib diisi (ditandai dengan *)
  3. Klik tombol Dapatkan Lokasi untuk mendapatkan koordinat GPS
  4. Klik tombol Simpan Data untuk menyimpan data

  1. Buka tab Backup & Restore
  2. Klik tombol Backup ke Excel atau Backup ke PDF
  3. File akan otomatis terunduh ke perangkat Anda
  4. Simpan file di lokasi yang aman

  1. Buka tab Backup & Restore
  2. Klik Pilih File dan pilih file backup Excel
  3. Klik tombol Restore Data
  4. Data akan dipulihkan dari file backup
