Tentang Aplikasi BARJAS

Informasi Aplikasi

BARJAS (Bantuan dan Rekam Jejak) adalah aplikasi untuk mengelola data bantuan Dinas Peternakan dan Perikanan Kabupaten Situbondo.

Aplikasi ini dirancang untuk memudahkan proses input, pengelolaan, dan pelaporan data bantuan yang diberikan kepada kelompok masyarakat.

Fitur Utama:
  • Input data bantuan dengan mudah
  • Penyimpanan data di browser (local storage)
  • Ekspor data ke Excel dan PDF
  • Statistik dan visualisasi data
  • Manajemen link Google Drive
  • Backup dan restore data
Teknologi

Aplikasi ini dibangun menggunakan teknologi web modern:

HTML5 CSS3 JavaScript Bootstrap 5 Chart.js LocalStorage

Beberapa library yang digunakan:

  • Bootstrap 5.3.0
  • Font Awesome 6.4.0
  • Chart.js
  • jsPDF dan jsPDF-AutoTable
  • SheetJS (xlsx)
  • Particles.js
