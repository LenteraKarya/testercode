Tentang Aplikasi

Informasi Aplikasi

BARJAS (Bantuan dan Penyerahan Barang) adalah aplikasi untuk mengelola data penyerahan bantuan dari Dinas Peternakan dan Perikanan Kabupaten Situbondo.

Aplikasi ini dirancang untuk memudahkan proses input data, monitoring, dan pelaporan penyerahan bantuan kepada masyarakat.

Versi: 2.5

Tanggal Rilis: 1 Januari 2025

Teknologi

Aplikasi ini dibangun dengan teknologi modern:

  • HTML5, CSS3, JavaScript
  • Bootstrap 5.3
  • Chart.js untuk visualisasi data
  • jsPDF dan jsPDF-AutoTable untuk ekspor PDF
  • SheetJS untuk ekspor Excel
  • Particles.js untuk efek latar belakang
