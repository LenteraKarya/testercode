Panduan Penggunaan

Isi form input data dengan lengkap dan benar. Pastikan NIK terdiri dari 16 digit angka. Nomor WhatsApp akan otomatis dikonversi ke format internasional (62).

Gunakan filter dan pencarian untuk menemukan data dengan cepat. Anda dapat memfilter berdasarkan tahun, sumber dana, dan jenis bantuan.

Lakukan backup data secara berkala untuk mencegah kehilangan data. Gunakan password untuk mengamankan file backup Anda.
