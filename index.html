Tentang Aplikasi

Informasi Aplikasi
APLIKASI BARJAS

Aplikasi Bantuan dan Jasa (BARJAS) merupakan sistem informasi untuk mengelola data bantuan yang diberikan Dinas Peternakan dan Perikanan Kabupaten Situbondo kepada kelompok usaha bersama (KUB).

Dengan aplikasi ini, proses input data, monitoring, dan pelaporan dapat dilakukan secara digital dan terintegrasi.

Fitur Utama
  • Input data bantuan dengan form lengkap
  • Pencarian dan filter data
  • Ekspor data ke Excel dan PDF
  • Statistik dan visualisasi data
  • Backup dan restore data
  • Manajemen link Google Drive

Panduan Penggunaan

  1. Buka tab Input & Data
  2. Isi semua field yang wajib diisi (ditandai dengan *)
  3. Pastikan NIK KTP terdiri dari 16 digit angka
  4. Nomor WhatsApp akan otomatis dikonversi ke format internasional (62)
  5. Klik tombol Simpan Data untuk menyimpan

  1. Buka tab Input & Data
  2. Gunakan filter untuk menyaring data yang ingin dicetak
  3. Klik tombol Cetak untuk mencetak laporan
  4. Pastikan printer sudah terhubung dan siap digunakan
  5. Laporan akan dicetak dalam format landscape

  1. Buka tab Backup & Restore
  2. Klik tombol Backup Data Sekarang
  3. File Excel akan otomatis terunduh
  4. Simpan file di lokasi yang aman
  5. Lakukan backup secara berkala untuk mencegah kehilangan data
