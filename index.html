Informasi Aplikasi
APLIKASI BARJAS

Aplikasi Bantuan Barang dan Jasa (BARJAS) merupakan sistem informasi untuk mengelola data penerima bantuan dari Dinas Peternakan dan Perikanan Kabupaten Situbondo.

Aplikasi ini dirancang untuk memudahkan proses input data, monitoring distribusi bantuan, serta menghasilkan laporan secara cepat dan akurat.

Fitur Utama:
  • Input data penerima bantuan
  • Manajemen data dengan filter dan pencarian
  • Ekspor data ke Excel dan PDF
  • Statistik dan visualisasi data
  • Backup dan restore data
  • Keamanan data dengan password
Teknologi:
  • HTML5, CSS3, JavaScript
  • Bootstrap 5.3.0
  • LocalStorage untuk penyimpanan data
  • Chart.js untuk visualisasi data
  • SheetJS (xlsx) untuk ekspor Excel
  • jsPDF untuk ekspor PDF
