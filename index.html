Panduan Penggunaan

Isi semua field pada form input data, kemudian klik tombol "Simpan Data". Pastikan data yang dimasukkan valid.

Pergi ke menu "Backup & Restore", pilih format backup, lalu klik tombol "Backup Data Sekarang".

Gunakan tombol "Cetak", "Excel", atau "PDF" di atas tabel data untuk mencetak laporan.
