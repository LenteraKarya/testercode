Informasi Aplikasi
APLIKASI BARJAS (Bantuan Peternakan dan Perikanan)

Aplikasi ini dikembangkan untuk Dinas Peternakan dan Perikanan Kabupaten Situbondo untuk mengelola data bantuan yang diberikan kepada masyarakat.

Fitur Utama:
  • Input data bantuan dengan form yang lengkap
  • Penyimpanan data secara lokal di browser
  • Backup dan restore data ke/dari file Excel
  • Statistik dan visualisasi data
  • Manajemen link Google Drive
  • Ekspor data ke PDF dan Excel
  • Pencetakan laporan data
Teknologi:
  • HTML5, CSS3, JavaScript (ES6+)
  • Bootstrap 5.3.0
  • Font Awesome 6.4.0
  • Chart.js untuk visualisasi data
  • SheetJS (xlsx) untuk manipulasi Excel
  • jsPDF untuk ekspor PDF
  • LocalStorage untuk penyimpanan data

Kebijakan Privasi & Keamanan
Keamanan Data

Data yang dimasukkan ke dalam aplikasi ini disimpan secara lokal di browser pengguna. Pastikan untuk melakukan backup data secara berkala untuk mencegah kehilangan data.

Privasi

Aplikasi ini tidak mengumpulkan atau membagikan data pribadi pengguna kepada pihak ketiga. Semua data tetap berada di perangkat pengguna.

Rekomendasi Keamanan
  • Ganti password default setelah pertama kali menggunakan aplikasi
  • Lakukan backup data secara berkala
  • Jangan bagikan file backup kepada pihak yang tidak berwenang
  • Gunakan perangkat yang aman dan terpercaya
