Tentang Aplikasi

Informasi Aplikasi

APLIKASI BARJAS (Bantuan dan Jasa) merupakan sistem informasi untuk mengelola data serah terima bantuan dari Dinas Peternakan dan Perikanan Kabupaten Situbondo.

Fitur Utama:
  • Input data serah terima bantuan
  • Manajemen data KUB (Kelompok Usaha Bersama)
  • Statistik dan laporan bantuan
  • Backup dan restore data
  • Ekspor data ke Excel dan PDF
Teknologi:
  • HTML5, CSS3, JavaScript (ES6+)
  • Bootstrap 5.3.0
  • Font Awesome 6.4.0
  • Chart.js untuk visualisasi data
  • jsPDF untuk ekspor PDF
  • LocalStorage untuk penyimpanan data
